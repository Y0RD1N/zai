# Mantenimiento de Zai

Zai es un proyecto público mantenido exclusivamente por Yordi (@Y0RD1N).
Actualmente no se aceptan contribuciones de código ni pull requests externas.
Solo el propietario autoriza cambios y publica las versiones oficiales.

La licencia MIT permite utilizar, modificar y distribuir copias con su aviso de
copyright y licencia. Esos permisos no otorgan acceso de escritura a este repositorio.
Los instaladores oficiales están en https://github.com/Y0RD1N/zai/releases.

Las ramas y etiquetas están restringidas al usuario Y0RD1N mediante reglas de
GitHub. Los workflows solo se ejecutan por ese propietario, con acciones fijadas
a commits completos y permisos mínimos. Las compilaciones no pueden escribir
código en el repositorio; el trabajo de publicación solo recibe permiso para
subir los instaladores después de que todas las plataformas hayan pasado.
